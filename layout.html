Layout

Layout is how the brand holds together on any surface. Three ways to create layouts with our visual design system — all anchored by one grid — so every banner, screen, and page feels unmistakably Headout.

Three ways to lay out

Our visual design system gives every layout a starting point — type-led, image-led, or device-led. Whichever way you build, the same ingredients and the same grid keep the result recognisably Headout.

The grid system

A system to standardise how we lay out content: one grid with consistent columns, gutters, and margins across every breakpoint. Set the grid first — then the layout takes care of itself.

Grids in action

What the grid is actually doing underneath — real communications with their construction exposed, showing how content snaps to columns at any size.

Use cases

The system at work across real campaigns and touchpoints — different formats, one recognisable layout language.

Portals

Portals are Headout's visual device for framing experiences — a threshold between the viewer and the destination. What we seek in an experience, how the portal adapts to every format, and where it shows up in the world.
